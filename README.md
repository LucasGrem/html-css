# Curso HTML5 e CSS3 – Curso em Vídeo

Este repositório contém os exercícios e projetos desenvolvidos durante o curso gratuito de **HTML5 e CSS3** oferecido pelo **Curso em Vídeo**, com carga horária total de **40 horas** cada módulo.

O curso foi ministrado pelo professor **Gustavo Guanabara**, abordando os principais fundamentos do desenvolvimento web moderno, com foco em HTML5, CSS3 e design responsivo.

## Conteúdo abordado

### Módulo 1: Introdução ao HTML5

- Estrutura básica de uma página HTML
- Elementos e tags essenciais
- Atributos de tags
- Listas, tabelas e links

### Módulo 2: Introdução ao CSS3

- Seletores e propriedades CSS
- Cores, fontes e textos
- Box model (margem, borda, padding)
- Layouts básicos com CSS

### Módulo 3: Avançando no CSS3

- Estilos para listas e tabelas
- Pseudo-classes e pseudo-elementos
- Estilizando formulários
- Transições e animações simples

### Módulo 4: Iframes, Formulários e Design Responsivo

- Uso de iframes para incorporar conteúdo externo
- Criação de formulários com diversos tipos de campos
- Métodos GET e POST
- Introdução ao design responsivo com media queries
- Projeto prático: tela de login responsiva
- FlexBox

### Módulo 5: Projeto Final e Boas Práticas

- Desenvolvimento de um site completo utilizando HTML5 e CSS3
- Grid Layout
- Aplicação de boas práticas de codificação
- Validação de código HTML e CSS
- Otimização para dispositivos móveis
- Publicação do site na web
